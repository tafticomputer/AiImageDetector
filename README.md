# تشخیص تصویر هوش مصنوعی (اندروید)

برنامه‌ای که یک تصویر یا فایل PDF را می‌گیرد و بررسی می‌کند آیا تصویر با هوش مصنوعی ساخته شده است یا نه.

## ساخت APK در گیت‌هاب
1. یک مخزن (repository) جدید در GitHub بسازید.
2. همه‌ی فایل‌های این پروژه را (از جمله پوشه‌ی `.github`) در آن آپلود یا push کنید.
3. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا از دکمه‌ی *Run workflow* اجرا کنید).
4. پس از پایان، از انتهای صفحه‌ی همان اجرا، بخش **Artifacts** فایل `AiImageDetector-debug-apk` را دانلود کنید و `app-debug.apk` را از حالت zip درآورید.
5. APK را روی گوشی نصب کنید (اجازه‌ی نصب از منبع ناشناس لازم است).

## روش تشخیص
- **متادیتا:** برچسب IPTC «AlgorithmicMedia»، نام ابزارهایی مثل Midjourney، DALL·E، Stable Diffusion، Firefly، ComfyUI، پارامترهای پرامپت داخل PNG، و وجود C2PA.
- **EXIF:** وجود یا نبود اطلاعات دوربین.
- **آمار پیکسلی (نشانه‌ی ضعیف):** سطح نویز، یکنواختی نویز، ابعاد مضرب ۶۴.
- **PDF:** متادیتای سند + استخراج تصاویر JPEG داخل PDF و تحلیل هرکدام.

## محدودیت‌ها
- نتیجه قطعی نیست. تصویر ساخته‌شده‌ای که متادیتایش حذف شده (مثلاً اسکرین‌شات یا ارسال از پیام‌رسان) فقط با نشانه‌های ضعیف بررسی می‌شود.
- تصاویر PDF که با فشرده‌سازی غیر از JPEG ذخیره شده‌اند استخراج نمی‌شوند.
- برای دقت بالاتر باید یک مدل یادگیری ماشین (مثل TFLite) یا سرویس تشخیص آنلاین به برنامه اضافه شود.
